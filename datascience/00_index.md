## The ML Workflow

```
1. Get data
2. Clean it (nulls, outliers, encoding)
3. EDA (explore, visualize)
4. Feature engineering
5. Split: train / val / test
6. Train model
7. Evaluate with right metric
8. Tune hyperparameters
9. Deploy + monitor
```

---

## Types of ML

| Type | When | Example |
|------|------|---------|
| Supervised | You have labels | Predict price, classify spam |
| Unsupervised | No labels | Customer segmentation |
| Semi-supervised | Some labels | Image classification with few labels |
| Reinforcement | Agent learns by reward | Game AI |

---

## Pick the Right Model

| Problem | Start With |
|---------|-----------|
| Tabular data (any) | XGBoost / LightGBM |
| Images | CNN (ResNet, EfficientNet) |
| Text | BERT / transformers |
| Clustering | K-Means |
| Anomaly detection | Isolation Forest |
| Time series | LightGBM with lag features / Prophet |
| Small dataset | Ridge / Lasso / SVM |
| Baseline | Logistic Regression |
